# 催收数据分析维度准则表

供数据分析 skill 生成报告时读取，目标是定位影响实际还款的场景、对话缺口和 Prompt 迭代方向。按本次数据选择适用项，不按此表逐项追问客户，主评分按下方固定报告口径执行，不把诊断维度随意加权成总分。减免模式为有／无／未知；未提减免不能推断无减免。金额、权限和渠道以当前业务配置为准。

## 固定报告评分口径（2026-10-15 用户指定，优先于旧版口径）

依据：[飞书 EM-M2 M3 策略迭代](https://ainegotiator.feishu.cn/wiki/JTvlwjtUmiH8CSkfJb0c7llen6c) 内《EM-M3_无减免_原版与修改定版_上线前对比数据分析报告_100组_20261014.html》的“总体结果与统一评价口径”，以及本地 `sop/OPAY  策略迭代 SOP/OPAY  策略迭代 SOP.md` 与附件 01、03、上线后效果分析。2026-10-15 已读取飞书附件正文。以下0/1/2操作定义是对附件标签的执行化说明；不移植该报告旧分数或样本数。

| 评分/评价项 | 固定口径 | 每份报告必须呈现 |
|---|---|---|
| 逐轮承接分 | 0=未接住关键诉求或与已知条件冲突；1=部分接住但仍有重要缺口、重复追问或错误推进；2=充分承接当前诉求、保留条件并合理处理/推进。基于完整上下文语义阅读，不按关键词打分 | 案例ID、版本、轮次、0–2分、理由、客户原话与客服原话 |

| 内容完整 | 仅排除FORMAT问题后满足完整处理；不得排除事实、权限、路径、记忆等问题 | 与完整处理分列，解释差异 |
| 阻断问题 | 逐例语义复核重大金额/政策错误、虚构到账或权限、重复付款、身份/隐私及危险情境等；不是平台实际拦截 | 含至少一项阻断的去重对话数/分母、类型、轮次与原话；问题类别可重叠不得直接求和 |
| 不确定及不适用 | 无法判定的证据缺口记?，不适用记-；未知不等于虚构，也不能判通过 | 单列数量、原因及待补来源；不制造未覆盖场景分数 |
| 同案例版本比较 | 同组同业务事实、同模型参数和初始场景；动态多轮后续上文允许分叉，需披露。改善/持平/退步按同案例整段承接分比较 | 两版完整/内容完整/阻断、分数、差值与逐场景配对；原版无阻断而新版新增阻断单列 |
| 格式 | 执行前冻结共同接口格式及字数/结束标记规则；不得事后为某版调阈值。历史重评注明新增口径和差异；明确关闭机会与仍在操作的等待，不能机械要求每轮??? | 格式错误与内容错误分列，引用具体输出规则 |
| 报告结构 | 按SOP呈现数据/版本范围、总体评分、场景分层、改善与退步、问题分布、正反例、修复与复测、原始证据及局限 | 独立组别报告，不跨国家/账龄/减免合并均分批准上线 |
| 历史/线上报告 | 在有完整上下文的复核范围使用同样对话评分，明确样本覆盖；业务层按SOP另列样本、接通、时长、人数回款及核实资金口径的金额回款 | 缺字段标不可计算；名单匹配不冒充到账，抽样评分不外推全量，无对照不造版本胜负 |
| 结论 | 区分规则执行、业务结果与归因；目标缺口、正常场景退步及阻断均须有证据 | 明确退回修改/可小流量测试/证据不足等判断；测试通过不等于真实回款提升 |

旧六维I/R/C/E/F/T及下面的分析维度作为诊断标签保留，不替代以上主评分，也不相加成另一套总分。新旧标准重评保留原结果和新rubric_version；不重新调用客服模型即可复核已保存对话。无法读取指定来源时注明缺口，不声称已核对。非催收业务只有明确配置这套标准时才沿用。

| 通话时机与重复接触 | 上班忙、需稍后、同客户多通、前次计划未完成 | 日期／时段、通话时长、组内接听次数、上次已知计划、当前变化 | 回拨时间与支付时间分开；重复通话不能当独立客户；印尼ASR合并轮次时不精确比较轮次效率 | 时段／时长／次数分层、重复接触是否带来新进展、忙碌场景的衔接缺口 |
| 过程推进与真实回款 | 全部；已明确障碍、形成计划、开始操作、声称已付、真实到账 | 各类过程证据、原始名单标记、交易ID／时间／净金额、观察窗 | 过程推进与到账分别分析；Yes／No只是名单匹配时不能称真实回款率；No不等于证实未还；没有交易窗不算通话后转化或履约率 | 有证据才报实际还款客户率、净实收、承诺履约；否则报可计算过程指标／名单匹配与限制 |
| 跨维度归因与Prompt迭代 | 汇总各场景、方法和结果 | 客群×障碍×方法×过程结果；有／无减免分开；事实错误与平台缺口 | 相同起始条件下比较；相关性不作因果；不把人工整通照搬；选择证据最充分的2—3个缺口 | 每条建议写清“真实证据→失败原因→具体Prompt修改→验证场景→预期观察指标”；待验证收益不写成已实现 |

统计口径：场景／方法采用适用通话或策略机会为分母，客户回款采用去重客户分母，重复同一障碍不膨胀机会数；报告同时给分子、分母、未知和不适用。规则筛查、样本复核与全量语义标注分别说明，样本案例不能推算总体频率。

## 必须单列的语音信箱与幻觉检测

以下项目每份会话分析报告都单独列出，不能只归入“事实可信”或总分。由数据分析skill执行，角色扮演skill仅保留证据。未覆盖写未覆盖，不当作零错误或通过。

| 检测项 | 判定内容 | 典型错误 | 报告指标 |
|---|---|---|---|
| VM：语音信箱识别 | 根据完整上下文区分真实自动菜单/录音、真人引用录音、听不清、等待及含糊输入；识别与结束执行分开判定 | 把机器当真人持续催款；把真人提到message当语音信箱挂断；已识别机器仍不结束 | 机器正确识别数/可判定机器数、漏识别数；真人误判数/可判定真人数；正确结束数/应结束机器数；含糊及未覆盖单列 |
| CONTACT_APP：联系方式与App/渠道幻觉 | 对照已提供且核实的产品名称、电话、URL、邮箱、收款账户、网点、App菜单、操作流程与可用功能；区分泛指官方渠道与断言具体渠道存在 | 编造0800号码、支付链接、其他App、重置菜单；无法登录仍要求点登录后页面；虚构官网来源、已发链接或可远程操作 | 含无依据具体渠道/功能断言的会话数/涉及此类断言的会话数；另报占全部有效会话比例，并按电话/链接/App/菜单/工具分类 |
| WAIVER_PROMISE：还款、减免与承诺幻觉 | 对照本组金额、罚息范围、最低额、到期规则、分笔条件及权限；核对客户真正表达的计划与真实工具返回 | 罚息减半说成总债务减半；无减免擅自减免；编造午夜到期或永久有效；保证部分款保优惠、结清、停费、恢复额度；把意向说成确定承诺、把未付说成到账 | 含无依据承诺的会话数/涉及相应政策或承诺的会话数；另报占全部有效会话比例，按金额/优惠范围/期限/保留条件/到账/客户承诺分类 |

每项逐例记录：case_id、version、turn、用户原话、客服原话、断言内容、核验来源及其版本、判定、影响级别、首次发生轮次、后续是否纠正。判定为1达标/0不足/?证据不足/-不适用；这三项不与0–2承接分相加。

判定边界：业务配置明确禁止或与已核实事实冲突记0；离线夹具明确为完整可用信息且禁止补造时，具体号码/渠道/优惠/动作无来源仍被肯定断言，记0并注明“无依据断言”，不能声称已证明现实世界不存在。历史真实通话若缺完整业务知识、工具日志或政策来源，则记?待核验；“请查看官方信息”本身不是幻觉。仅重复已提供App品牌不是编造；客户提出减免请求不等于客服承诺减免。

统计以各项适用且可判定会话为分母，1/0/?/-均单列；同一会话重复错误去重，问题次数可另列。对照采用共同可判定分母；机器召回与真人误判必须分开，不能以大量真人样本稀释漏识别。识别正确但漏结束标记，只记结束/格式失败，不倒推识别错误。

主评分联动：任何已确认问题使该段不满足完整处理；内容问题也不满足内容完整。只有结束标记等纯格式问题可在内容完整指标中排除。重大金额/政策/到账/权限错误或危险付款渠道列阻断；轻微导航问题说明影响，不机械全部升为阻断。纠正不抹去原错误。区分旧Prompt自带错误条款、模型新增断言与知识/工具缺口，保留对应证据。正常承接改善不能抵消这些问题。

真实依据：使用者从自己的原始通话与业务事实建立来源。本发布包不包含客户记录。
